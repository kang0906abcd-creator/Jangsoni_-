# 나가기 설문 (별점 + 개선 제안)

사용자가 사이트를 떠나려 할 때 장손이가 등장해 별점(1~5)과 개선 제안을 부탁합니다. "다음에 할게요"로 건너뛸 수 있습니다. 응답은 운영자의 **구글 시트**에 한 줄씩 쌓입니다.

## 언제 나타나나요?

| 상황 | 동작 |
| --- | --- |
| PC에서 마우스를 창 위쪽(탭·주소창·닫기 버튼)으로 옮길 때 | 설문 표시 |
| 첫 화면에서 브라우저 **뒤로 가기**로 사이트를 떠나려 할 때 (휴대전화 포함) | 설문 표시 → 응답하거나 건너뛰면 원래 가려던 이전 페이지로 이동 |
| 휴대전화에서 다른 앱·탭에 갔다가 돌아왔을 때 | 설문 표시 |
| 기능을 끝까지 쓴 직후 (카드뉴스 저장, 약관 분석 결과 표시, 논문 인용 복사) | 3.5초 뒤 "방금 기능, 도움이 됐나요?"로 표시 (입력 중이면 건너뜀) |
| 장손이 도움말 창의 **의견 보내기** 버튼 | 언제든 바로 표시 (횟수 제한 없음) |
| 주소 뒤에 `?survey`를 붙여 열 때 | 바로 표시 (확인·시연용) |

- 접속 후 8초가 지나야 나타나고, 한 번 방문에 한 번만 묻습니다.
- 응답을 보낸 사람에게는 30일 동안 다시 묻지 않습니다. 건너뛴 사람은 다음 방문 때 다시 권유합니다.
- 브라우저 보안 정책상 **탭 닫기 버튼을 누른 순간**에는 어떤 사이트도 직접 만든 화면을 띄울 수 없습니다. 그래서 PC는 마우스가 닫기 버튼 쪽으로 가는 순간을 미리 잡아 설문을 띄웁니다.
- 숫자는 `src/survey-config.json`의 `minEngagementSeconds`, `askAgainAfterDays`에서 바꿀 수 있습니다.

## 응답을 모을 구글 시트 연결 (처음 한 번)

1. [Google 스프레드시트](https://sheets.new)에서 새 시트를 만들고 이름을 `장손이 설문`처럼 지정합니다.
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 코드를 지우고 `scripts/survey-apps-script.gs` 내용을 그대로 붙여 넣은 뒤 저장합니다.
4. 위쪽 함수 선택에서 `setup`을 고르고 **실행**을 누릅니다. 권한 승인 창이 나오면 본인 계정으로 허용합니다. 시트에 `설문응답` 탭이 생깁니다.
5. 오른쪽 위 **배포 → 새 배포 → 유형: 웹 앱**을 고르고
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
   로 배포합니다.
6. 표시되는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사해 `src/survey-config.json`의 `endpoint`에 넣습니다.
7. `npm run build` 후 커밋·푸시하면 배포된 사이트에서 바로 시트로 응답이 들어옵니다.

연결 전에 받은 응답은 응답자의 브라우저에 보관했다가, 그 사람이 연결 후 다시 방문할 때 자동으로 전송됩니다.

## 응답 확인

`설문응답` 시트에 다음 열이 쌓입니다.

| 받은 시각 | 제출 시각 | 별점 | 개선 제안 | 화면 | 계기 | 기기 | 화면 크기 | 처리 상태 |

- `화면`: 응답할 때 보고 있던 화면(시작 화면, 약관, 분쟁조정 등)
- `계기`: 창 닫기 직전 / 뒤로 가기 / 다른 앱에서 복귀
- `처리 상태`: 처음엔 `미확인`. 반영 여부를 직접 `반영 완료`, `보류` 등으로 바꿔 관리하세요.

이름·이메일·IP 같은 개인정보는 수집하지 않습니다.
